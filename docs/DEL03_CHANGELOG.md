# DEL03 changes

## Revisions since DEL01

- Grounded the inquiry in TikTok's deployed For You feed rather than a fictional short-form platform.
- Specified one simulated viewer and 20 recommendation rounds.
- Revised the inquiry question to examine changes in category distribution without assuming the direction of the outcome.
- Clarified that the model selectively represents a recommendation feedback process, not TikTok's actual algorithm.
- Narrowed the planned low/medium/high comparison to the two conditions implemented in DEL02.

## Documentation changes for DEL03

- Updated the README to reflect the final inquiry and its limits.
- Documented the existing model settings, output filenames, evidence labels and results.
- Prepared supporting records for synthetic inputs (E5) and model outputs (E6).
- Developed the final ecosystem map and expanded interpretation of the comparison in the online dossier.
- Identified limitations, including repeated baseline videos, a fixed seed and the synthetic feedback rules.

## Retained implementation

The DEL03 comparison retains the DEL02 model and experimental conditions. No new recommendation rule or experimental condition was introduced.
